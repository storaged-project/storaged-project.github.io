bd_s390_zfcp_scsi_offline ()

gboolean
bd_s390_zfcp_scsi_offline (const gchar *devno,
                           const gchar *wwpn,
                           const gchar *lun,
                           GError **error);

Parameters

devno

zfcp device number

  

wwpn

zfcp WWPN (World Wide Port Number)

  

lun

zfcp LUN (Logical Unit Number)

  

error

place to store error (if any).

[out][optional]

Returns

whether a LUN was successfully removed from its associated WWPN

This function looks through /proc/scsi/scsi and manually removes LUNs from associated WWPNs. zFCP devices are SCSI devices accessible over FCP protocol. In z/OS the IODF (I/O definition file) contains basic information about the I/O config, but WWPN and LUN configuration is done at the OS level, hence this function becomes necessary when switching the device offline. This particular sequence of actions is for some reason unnecessary when switching the device online. Chalk it up to s390x being s390x.

Generates a new secure key for pervasive encryption using the 'zkey' utility and stores it in the secure key repository. The key is generated as an XTS key with the 'LUKS2' volume type.

Parameters

name

name of the secure key to generate in the secure key repository

  

key_type

type of the secure key to generate (e.g. "CCA-AESCIPHER") or NULL for the zkey default.

[nullable]

keybits

size of the key in bits or 0 for the zkey default

  

volumes

list of volumes to associate with the key, each given in the "volume:dmname" format, or NULL.

[nullable][array zero-terminated=1]

apqns

list of cryptographic adapters (APQNs) to associate with the key, each given in the "card.domain" format, or NULL.

[nullable][array zero-terminated=1]

sector_size

sector size in bytes to use with dm-crypt or 0 for the system default

  

dummy_passphrase

whether to generate and associate a dummy passphrase with the key

  

extra

extra options for the key generation (right now passed to the 'zkey' utility).

[nullable][array zero-terminated=1]

error

place to store error (if any).

[out][optional]

Returns

whether the secure key was successfully generated or not

bd_s390_zkey_cryptsetup_setvp ()

gboolean
bd_s390_zkey_cryptsetup_setvp (const gchar *device,
                               const gchar *key_file,
                               const BDExtraArg **extra,
                               GError **error);

Sets the verification pattern of the secure key in the metadata of the LUKS2 volume device using the 'zkey-cryptsetup' utility. The verification pattern is used to identify the secure key associated with the volume. Setting the verification pattern requires unlocking a keyslot of device , so the LUKS passphrase needs to be provided in key_file (this is a passphrase file, not the secure key file).

Parameters

device

LUKS2 device to set the verification pattern on

  

key_file

path to a file containing the LUKS passphrase used to unlock a keyslot of device

 

extra

extra options for setting the verification pattern (right now passed to the 'zkey-cryptsetup' utility).

[nullable][array zero-terminated=1]

error

place to store error (if any).

[out][optional]

Returns

whether the verification pattern was successfully set or not
